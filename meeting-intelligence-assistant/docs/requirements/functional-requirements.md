Define what the system must do.

Example:

FR-001
The system shall allow authenticated users to upload meeting transcripts.

FR-002
The system shall generate a meeting summary.

FR-003
The system shall extract action items.

FR-004
The system shall extract key decisions.

FR-005
The system shall allow users to ask questions about meetings.

FR-006
The system shall provide transcript references for generated answers.
This will be extremely useful for your 40% System Requirement Testing.
